# Exchanger for iOS

Native SwiftUI currency converter — the iOS version of [exchanger.in.ua](https://exchanger.in.ua). Rates: Monobank buy/sell, NBU official rate, and mid-market rates from fawazahmed0/exchange-api.

```sh
brew install xcodegen
xcodegen generate
open Exchanger.xcodeproj
```

Signing is automatic with team `C8L8G6WU6L`. Releasing to the App Store: see [AppStore.md](AppStore.md).
